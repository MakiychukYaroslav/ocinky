# Оцінки онлайн

Сайт, де викладачі ставлять оцінки, а батьки переглядають оцінки своєї дитини за особистим кодом.

- **Батьки:** головна сторінка → код дитини → оцінки з усіх предметів, середні бали, пропуски, коментарі.
- **Викладачі:** «Вхід для викладачів» → пошта й пароль → «Журнал».
- **Адміністратор:** вкладка «Адміністрування»: коди для батьків і їх друк, студенти, викладачі, предмети й групи.

Дані зберігаються в Supabase (проєкт `ocinky-online`). Ключ у `app.js` публічний: він дає доступ лише до того, що дозволяють правила бази.

## Як опублікувати на GitHub Pages (≈10 хвилин, лише браузер)

1. Увійдіть на https://github.com і натисніть **New repository** (зелена кнопка або «+» угорі праворуч).
2. Назва, наприклад, `ocinky`. Оберіть **Public**. Натисніть **Create repository**.
3. На сторінці репозиторію натисніть посилання **uploading an existing file**.
4. Перетягніть у вікно файли `index.html`, `style.css`, `app.js` (і цей `README.md`). Натисніть **Commit changes**.
5. Відкрийте **Settings → Pages**. У розділі «Build and deployment» оберіть **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)**, натисніть **Save**.
6. Через 1–2 хвилини вгорі сторінки Pages з’явиться адреса виду `https://<ваш-логін>.github.io/ocinky/`. Це адреса сайту.

### Після публікації — один раз у Supabase

Supabase → **Authentication → URL Configuration** → у полі **Site URL** вкажіть адресу сайту з кроку 6 і збережіть.

### Як оновити сайт

Відкрийте репозиторій → **Add file → Upload files** → перетягніть оновлені файли → **Commit changes**. Через хвилину зміни на сайті.

## Перший вхід

1. Відкрийте сайт → **Вхід для викладачів** → ваша пошта й пароль із Supabase.
2. **Адміністрування → Коди для батьків** → оберіть групу → **Друкувати аркуш з кодами**.
3. **Адміністрування → Викладачі** → «Новий викладач»: ПІБ, пошта, предмети й групи → **Створити акаунт**. Сайт покаже тимчасовий пароль — передайте його викладачу.

## Журнал

- «Додати колонку» — дата й вид роботи (практична, тест, контрольна…).
- У клітинку вписується 1–12 або «н». Enter / ↓ — наступний студент. Порожня клітинка = оцінки немає.
- Зберігається одразу; батьки бачать відразу.
- «Коментар» біля студента — повідомлення, яке побачать батьки в цьому предметі.
